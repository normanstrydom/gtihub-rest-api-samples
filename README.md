# gtihub-rest-api-samples

##  Requirements

*   JAVA_HOME=F:\java\openlogic-openjdk-17.0.18+8-windows-x64
*   MVN_HOME=F:\java\apache-maven-3.9.13

Running on windows 11

Github PAT set in environment variable - GITHUB_TOKEN  

Rest calls to be implemented using java.net.http.HttpClient

Write simple Java/Maven application to list user repositories, display packages for each repository, display versions for each package, display assets for each package version and display download url for each asset.

Seperate application into Main, RestUtils and GithubRest classes.
